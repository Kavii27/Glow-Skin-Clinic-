# Glow Admin Suite

Design a premium luxury admin dashboard for Glow Skin Clinic by Dr. Apeksha Herath, an exclusive aesthetic dermatology clinic.

This is NOT a typical SaaS dashboard.

The design should feel like software built specifically for a high-end cosmetic clinic, combining elegance, minimalism, luxury, and modern medical professionalism.

Technology

Generate only the frontend UI.

 React

 Tailwind CSS

 Fully responsive

 Component-based architecture

 Clean JSX structure

 No backend

 No dummy charts unless meaningful
